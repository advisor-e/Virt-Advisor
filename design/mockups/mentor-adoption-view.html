Adoption across firms

Which firms are actually using the product, and which have gone quiet. This replaces the Team Progress tab at mentor level — that tab lists a firm's advisers by name, which is a firm manager's view of their own people and must not cross the firm boundary. The same underlying activity, counted one level up and stripped of who did it, answers a question a mentor actually has: where is the product landing, and where is it not?

The last row is the whole design question, and it is not cosmetic. Activity is recorded in the session tables, which only ever hold rows for firms that have done something. A firm that has never opened the product leaves no trace there at all — so it cannot appear on this page unless the page also reads the list of firms itself. That is the difference between "here is who is using it" and "here is who is not", and the second is the more useful of the two. Reading that list would be the first time anything in our backend queries the firms table, and it must exclude the reserved __platform__ row seeded for mentor storage — which is not a firm. Same read gives us the firm names above; without it every row is an opaque id like firm-pf-019.

3 · What is not decided

Listed here rather than guessed at, so that approving this page approves something specific. Nothing below has an answer yet.

Decisions

  1. Read the firms list, or not? Without it, firms that have never started are invisible and every row shows an id instead of a name. With it, the page answers "who has not adopted this" — but it is a new database read, and in the Advisor-e master app that table may be theirs rather than ours. Recommendation: read it, and fall back to showing the id when a name is missing, so the page degrades to today's information rather than to an error.
  2. Should "Avg quiz" be here at all? It carries no names, but it is still a judgement about a firm's people rather than about adoption. It can be dropped without affecting anything else on the page. No recommendation — this is a product call.
  3. What counts as "gone quiet"? The mockup uses 30 days for active and anything older for quiet. Both numbers are invented.
  4. Every word marked like this. Page title, column headings, the three status badges, and the four tile labels. None of it is decided.

4 · The other tab, for completeness

Not part of this screen, but part of the same change, and recorded here so the artefact matches what gets built.

Team Case Studies disappears from the Mentor Hub. It is the firm manager's view of their own advisers' shared cases, and shows nothing at mentor level. The mentor already has the correct version beside it — the Case Reviews tab, which shows only cases a firm manager has anonymised and explicitly approved for sharing. Rolling the firm tab up instead would have walked straight past that consent gate, so it is hidden, not widened.
